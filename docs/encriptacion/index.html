¿Qué es la encripción y cómo funciona? Una explicación simple pero completa

Supongamos que usted quiere enviar un mensaje a otra persona, pero no quiere que nadie pueda entender el mensaje más que la persona a quién va dirigido. Lo que haría entonces es escribirlo en algún tipo de código, que solamente la persona indicada pueda descifrar, eso es encripción.

¿Cómo puede hacerlo? Una forma sencilla es codificar el mensaje cambiando cada una de las letras del mensaje, a otra letra, siguiendo una regla de sustitución. Así por ejemplo, la letra “a” la sustituye por “b”, la “b” por “c” y así sucesivamente hasta la “z” que se sustituye en “a”. Entonces la palabra “secreto”, se convertiría en “tfdsfup”. Una vez que el receptor recibe el mensaje, lo sustituye de regreso. “a” en “z”, “b” en “a”, etc. así descifra el mensaje. Tanto el que envía como el que recibe deben conocer el procedimiento.

Pero este esquema sería muy fácil de descifrar para cualquiera, entonces tal vez podemos hacer un sistema que vaya cambiando la regla de cifrado. Hagamos ahora, que tanto remitente como receptor tengan una rueda de cifrado como esta:

Rueda de cifrado interactiva

Mueva el puntero de izquierda a derecha sobre la rueda para cambiar la clave, igual que en el ejemplo original. En pantalla táctil puede arrastrar sobre la rueda o utilizar el control.

Clave = 8

La rueda usa las 26 letras minúsculas y el espacio, tal como se deduce del ejemplo del artículo. Con clave 8, “esto es secreto” produce exactamente “xklgsxkskxvjxlg”.

Si mueve el mouse por encima (de izquierda a derecha) puede establecer qué regla de sustitución de letras se va a utilizar. El número de pasos que se mueve la rueda (a la derecha) la llamaremos Clave de Cifrado. Al mover la rueda le da una clave de cifrado, que es la que el remitente y receptor deben saber. Para codificar el mensaje, se sustituye la letra del círculo interior por una del exterior, y para descifrarlo al revés.

Así por ejemplo si se quiere enviar el mensaje “esto es secreto”, con la clave de cifrado 8, se convierte en “xklgsxkskxvjxlg”,

Noten como el remitente encripta convirtiendo de las letras interiores a las exteriores, y el que recibe lo hace al revés (lee de afuera hacia adentro).

El problema está en que ambos deben compartir la clave de cifrado para que el receptor pueda descifrar el mensaje ¿Cómo comparto esa clave?¿cómo hago para que nadie vea la clave?, tengo el texto cifrado, pero debo compartir la clave… lo que hago con la mano borro con el codo (como dice el dicho). Es acá donde las matemáticas juegan un rol importante. El secreto está en utilizar una función matemática con propiedades particulares que permite comunicar públicamente el mensaje codificado y la forma de hacer el cifrado, pero la clave para descifrar sólo la conoce el receptor y nadie más. Acá les voy a mostrar una forma muy simplificada de un protocolo para compartir claves de manera segura, basado en lo que llamamos criptografía asimétrica, que se conoce como método ElGamal.

Antes de mostrarle esta función matemática especial, hay una operación matemática que debo explicar y que pocos conocen que se llama Módulo. Explicó con un ejemplo. Supongamos que queremos repartir 3 piedras entre 2 personas. Dado que no podemos partir las piedras, les tocaría una piedra a cada una y nos sobraría una piedra, precisamente Módulo es lo que nos sobra al dividir de forma exacta (sin fracciones), así entonces 3 mod 2 = 1 (mod quiere decir módulo), es decir al dividir exactamente 3 entre 2, sobra 1.

De esta forma, la llave pública que es 14, y la fórmula con a=2 y n=29, es lo que cualquiera que quiera enviar mensaje debe conocer. Ahora el remitente prepara el mensaje,

Como ven en la figura, debe escoger un número al azar, en este caso 24, de allí calcula, usando la fórmula, lo que se llama una llave efímera que resulta ser 20, esta la comparte de manera abierta con el receptor. La clave de cifrado a utilizar se calcula utilizando la llave pública 14, y resulta ser 16. Se usa 16 en nuestra rueda de cifrado, y el mensaje “esto es secreto” se codifica a “pcdzkpckcpnbpdz”. El receptor recibe el mensaje cifrado y la llave efímera 20. Con eso, y su llave privada 13, utilizando la fórmula como se ve en la figura, recalcula la clave de cifrado 16, usa la rueda de cifrado, y puede entonces descifrar el mensaje “esto es secreto”. ¡Listo! Las tablas de detalle usan exponenciación modular por cuadrados sucesivos. El ejemplo sigue siendo deliberadamente pequeño y pedagógico, como advierte el artículo.

Este es un ejemplo simplificado, para ilustrar los cálculos y lo astuto de esta forma de encriptación. En la realidad, se deben escoger números muy grandes para llave privada y para n en la fórmula, de esa manera, aunque alguien podría intentar “crackear” estos valores, tardaría muchísimo tiempo en conseguirlos, lo cual lo hace impráctico. Especialmente para n, que además de un número muy grande, se utiliza lo que se llama un número primo seguro (“safe prime” en wikipedia). Claro, el protocolo de cifrado que utilizo en este ejemplo no es muy seguro, en la realidad se utiliza algo bastante más sofisticado, lo cual hace las cosas aún más difíciles para los hackers.

Esta estrategia de encripción es un modelo híbrido que usa un método simétrico para encriptar y un protocolo de intercambio de claves basado en lo que se conoce como llave asimétrica. Aplicaciones como WhatsApp, por ejemplo, lo utilizan cada vez que usted se comunica con alguien por el chat, claro, usted no tiene que hacer ningún cálculo, sino la aplicación lo hace por usted.
