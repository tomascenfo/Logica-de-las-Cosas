Cadenas de Markov: Ejemplo con un generador de texto básico

Hoy exploraremos las Cadenas de Markov, un modelo matemático muy interesante y útil, y veremos cómo se aplica en la generación de texto. Pero para comenzar, usemos un ejemplo más sencillo para entender mejor este concepto.

Imaginemos que deseamos comprender cómo su pareja elige qué ver en la televisión. Para ello, nos dedicamos a observar cada cambio de canal. Registramos el canal actual y a cuál se cambia después. Tras acumular una cantidad considerable de observaciones, comenzamos a notar ciertos patrones, particularmente en los cambios entre canales de deportes, comedia y noticias. Observamos que, estando en un canal de deportes, es más probable que el siguiente sea de noticias en lugar de comedia. Ilustremos esta situación con el siguiente diagrama,

Esto significa que, por ejemplo, de cada 10 veces que se cambia de un canal de deportes, en 8 ocasiones se elige un canal de noticias y sólo en 2 se opta por comedia. Siguiendo este método, identificamos patrones similares de transición desde otros canales. Esto nos permite completar el diagrama que se muestra a continuación,

Este proceso tiene una particularidad muy interesante. Observen cómo la elección del próximo canal no depende del canal que se estaba viendo hace horas, sino únicamente del canal actual. Este tipo de proceso, donde los cambios se basan solamente en el estado más reciente, sin ninguna o con muy poca 'memoria' del pasado, es lo que se conoce como un proceso de Markov. El diagrama que acabamos de describir es un ejemplo de una Cadena de Markov.

Formalmente una Cadena de Markov, es un modelo matemático que se usa para describir un tipo de sistema, que cambia de un estado a otro, dentro de un conjunto determinado de estados (los círculos en el diagrama). Estos cambios, o transiciones (representadas por las líneas en el diagrama), dependen sólo del estado actual del sistema, no de cómo llegó a ese estado. Esto se conoce como la propiedad de "sin memoria". Dicho de otro modo, el futuro de un sistema en una cadena de Markov depende sólo del presente y no del pasado.

En el caso de nuestro ejemplo sobre el cambio de canales, es fundamental observar que la selección del próximo canal depende exclusivamente del canal que se está viendo en ese momento, y no de los canales que se han visto anteriormente. ¿Cuál es la relevancia de este modelo en el contexto de la elección de canales? Desde el punto de vista de un observador, el proceso implica cierta incertidumbre: estando en un canal específico, hay varias opciones posibles para el siguiente canal, y es imposible predecir con certeza cuál será. Esta imprevisibilidad, en la que cada elección se fundamenta únicamente en el estado actual sin tener en cuenta los estados pasados, es lo que convierte a las Cadenas de Markov en una herramienta idónea para analizar estas situaciones.

Ahora pasemos a un modelo un poco más complejo: un generador de texto. Este es un sistema generativo que, partiendo de una palabra inicial, tiene la capacidad de crear una frase completa.

const CORPUS = document.getElementById("markovCorpus").textContent.trim();

function tokenize(text) {
  return text
    .replace(/[“”"()]/g, "")
    .replace(/\s+/g, " ")
    .trim()
    .split(" ")
    .filter(Boolean);
}

function cleanForLookup(token) {
  return token.replace(/^[¿¡]+|[.,;:!?…]+$/g, "");
}

function buildModel(text) {
  const raw = tokenize(text);
  const words = raw.map(cleanForLookup).filter(Boolean);
  const model = new Map();

  for (let i = 0; i < words.length - 1; i++) {
    const current = words[i];
    const next = words[i + 1];
    if (!current || !next) continue;
    if (!model.has(current)) model.set(current, new Map());
    const counts = model.get(current);
    counts.set(next, (counts.get(next) || 0) + 1);
  }

  const topTwo = new Map();
  for (const [word, counts] of model.entries()) {
    const ranked = [...counts.entries()]
      .sort((a, b) => b[1] - a[1])
      .slice(0, 2)
      .map(([token, count]) => ({ token, count }));
    topTwo.set(word, ranked);
  }
  return topTwo;
}

const MODEL = buildModel(CORPUS);

function resolveKey(input) {
  const exact = [...MODEL.keys()].find(k => k === input);
  if (exact) return exact;
  const lower = input.toLocaleLowerCase("es");
  const sameLower = [...MODEL.keys()].find(k => k.toLocaleLowerCase("es") === lower);
  return sameLower || input;
}

function pick(options) {
  if (!options || options.length === 0) return null;
  return options[Math.floor(Math.random() * options.length)];
}

function generate(start, maxWords = 12) {
  const first = resolveKey(cleanForLookup(start.trim()));
  if (!first || !MODEL.has(first)) return null;

  const selected = [first];
  const steps = [];
  let current = first;

  for (let i = 1; i < maxWords; i++) {
    const options = MODEL.get(current) || [];
    if (!options.length) break;

    const chosen = pick(options);
    const alternatives = options.filter(o => o.token !== chosen.token);
    steps.push({
      from: current,
      chosen: chosen.token,
      alternatives: alternatives.map(o => o.token)
    });

    selected.push(chosen.token);
    current = chosen.token;

    if (!MODEL.has(current)) break;
  }

  return { selected, steps };
}

function renderPath(result) {
  const path = document.getElementById("transitionPath");
  path.innerHTML = "";
  if (!result) return;

  result.selected.forEach((word, index) => {
    const step = document.createElement("div");
    step.className = "markov-step";

    const chosen = document.createElement("div");
    chosen.className = "chosen-word";
    chosen.textContent = word;
    step.appendChild(chosen);

    if (index < result.steps.length && result.steps[index].alternatives.length) {
      const alt = document.createElement("div");
      alt.className = "alternative-word";
      alt.textContent = result.steps[index].alternatives[0];
      alt.title = "Otra de las dos transiciones más frecuentes";
      step.appendChild(alt);
    }

    path.appendChild(step);

    if (index < result.selected.length - 1) {
      const arrow = document.createElement("span");
      arrow.className = "path-arrow";
      arrow.textContent = "→";
      path.appendChild(arrow);
    }
  });
}

function runGenerator() {
  const input = document.getElementById("seedWord");
  const status = document.getElementById("generatorStatus");
  const output = document.getElementById("generatedText");
  const maxWords = Number(document.getElementById("wordCount").value) || 12;
  const seed = input.value.trim();

  const result = generate(seed, maxWords);
  if (!result) {
    status.textContent = seed.toLocaleLowerCase("es") === "estaba"
      ? "El artículo sugiere probar con “estaba”, pero esa palabra no aparece en el corpus de referencia incluido en el propio documento."
      : `La palabra “${seed || "—"}” no aparece como estado de transición en el corpus. Pruebe con “estrella”, “que” o “vacío”.`;
    status.className = "generator-status warn";
    output.textContent = "";
    renderPath(null);
    return;
  }

  output.textContent = result.selected.join(" ");
  status.textContent = "Cada ejecución vuelve a escoger al azar entre las dos transiciones más frecuentes disponibles.";
  status.className = "generator-status";
  renderPath(result);
}

document.getElementById("generateBtn").addEventListener("click", runGenerator);
document.getElementById("seedWord").addEventListener("keydown", e => {
  if (e.key === "Enter") runGenerator();
});
document.getElementById("resetBtn").addEventListener("click", () => {
  document.getElementById("seedWord").value = "estrella";
  document.getElementById("wordCount").value = "12";
  runGenerator();
});
runGenerator();

Pronto notarán que los textos generados no son de alta calidad. La razón de esto es que la construcción de frases coherentes en lenguaje natural generalmente requiere tener en cuenta un contexto más amplio, no sólo la palabra anterior. Esto explica por qué los textos generados a menudo carecen de sentido. Un generador como este tiene similitudes con las funciones de 'autocompletar' en búsquedas o al rellenar formularios, pero no es muy eficaz para crear frases completas. Sin embargo, a pesar de sus limitaciones, un sistema de este tipo puede ser útil para estudiar estilos de escritura y detectar patrones particulares en los textos.

Esto nos lleva a los sistemas de inteligencia artificial generativa que conocemos hoy en día. Para generar textos utilizando un sistema matemático, como una red neuronal u otro método, es crucial mantener la 'atención' sobre el contexto de lo que expresa la frase. Es decir, la frase generada debe tener en cuenta el contexto en el que se produce, lo cual es considerablemente más complejo. El desarrollo de algoritmos que manejan bien esta tarea ha sido fundamental para la creación de sistemas como ChatGPT, que utilizamos actualmente (ver referencia al final).

Aunque este ejemplo es básico, comparte elementos fundamentales con los sistemas de inteligencia artificial generativa. Se entrena utilizando un 'corpus' de texto, emplea un método numérico para generar frases a partir de un texto inicial, y en el proceso de generación se incorporan elementos estocásticos. Este ejemplo, que además es sencillo de programar, puede ser muy útil para enseñar a los estudiantes cómo funcionan estos sistemas generativos.
